# 🚀 Asteroids Game

A simple Asteroids clone built using Python and Pygame. Pilot your spaceship, destroy incoming asteroids, and survive as long as you can!

## 🎮 Features

- Player-controlled spaceship that can rotate and shoot
- Randomly spawning asteroids with varying sizes and velocities
- Collision detection between bullets, asteroids, and the player
- Score tracking and game over state

## 🛠️ Installation

1. Clone the repository:

```bash
git clone https://github.com/BurandonC/Asteroids.git
cd Asteroids
```

```bash
pip install -r requirements.txt
```

#🚀 Running the Game
```bash
python main.py
```
